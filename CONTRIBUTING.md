# Contributing

Contributions and suggestions for improving the QR Code Attendance Scanner are welcome.

## Getting Started

1. Fork the repository.
2. Clone your fork locally.
3. Create a new branch for your changes.
4. Make and test your changes.
5. Commit your changes with a clear commit message.
6. Push the branch to your fork.
7. Open a pull request describing the changes.

## Development Guidelines

- Follow clean and readable Python coding practices.
- Use meaningful variable and function names.
- Do not commit passwords, API keys, email credentials, or participant data.
- Use fictional or anonymized data for testing.
- Test existing functionality before submitting changes.

## Reporting Issues

When reporting an issue, include:

- A clear description of the problem
- Steps to reproduce it
- Expected behavior
- Actual behavior
- Relevant error messages

## Security

Never include real credentials or sensitive participant information in issues, commits, or pull requests.
