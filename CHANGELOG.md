# Changelog

All notable changes and improvements to the QR Code Attendance Scanner project are documented here.

## Current Version

### Added
- QR-based participant verification
- Attendance tracking system
- Duplicate attendance prevention
- Email confirmation functionality
- PDF ticket generation
- CSV and Excel participant data support
- Sample participant dataset
- Environment variable configuration example
- Installation and usage documentation
- Troubleshooting guide
- Contribution guidelines

### Security
- Added `.gitignore` rules to prevent sensitive environment files from being committed.
- Added `.env.example` for safe configuration.
- Excluded real participant datasets from version control.

### Documentation
- Improved project README.
- Added project structure and workflow explanation.
- Added sample data documentation.
- Added troubleshooting instructions.
